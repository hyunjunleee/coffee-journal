# 2차 기능 설계 (지도·기록·분석·알림·배포)

> 상태(2026-09-28): 이 문서의 1–4장은 모두 구현되어 v1.1.0부터 배포 중이다. 아래는 설계 당시의 계획이고, 그 뒤 바뀐 점은 각 절 끝의 "이후"에 적었다. 현재 동작의 기준은 `docs/android-app-design.md`(특히 §2.3 22·30–33)다.

사용자 결정(2026-09): 한국 지도는 통계청 SGIS 기반 경계, 로스터리는 지도에 직접 위치를 찍고 네이버 지도·카카오맵으로 열 수 있게 한다. 추가 기능: 추출 비교표 + 계산기, SCA CVA 양식, 통계 화면, 추출 타이머, 해외·카페 지도, 알림 + 위젯, 고정 서명 키 + CI. AI 기능은 계속 보류.

공통 원칙: 모든 데이터는 기기 안에서 계산·저장한다(서버·계정 없음). 새 데이터는 웹 백업과 호환되게 기존 필드를 유지하고, 앱 전용 값은 백업의 확장 키로 왕복 보존한다. 외부 자료는 공식 출처와 대조하고 출처를 `출처 · 라이선스` 화면에 올린다.

## 1. 한국 커피 지도 (SGIS 경계)

### 1.1 데이터
- 원본: [vuski/admdongkor](https://github.com/vuski/admdongkor) `ver20260701` 행정동 경계(GeoJSON, WGS84). 통계청 통계지리정보서비스(SGIS) 행정동 경계를 보정한 자료로, SGIS 원자료는 공공누리 제1유형(출처표시), 가공분은 CC BY 4.0. 2026-07-01 기준 16개 시·도, 시·군·구 237, 행정동 3,558.
- 가공(빌드 도구 `tools/korea-map/`, 저장소에 포함): 행정동을 `sgg`·`sido` 코드로 병합 → 경계 단순화 → 앱 좌표로 투영 → Kotlin 참조 데이터(`domain/reference/KoreaMapData*.kt`) 생성. 앱에 내장한다.
- 온라인 수신을 쓰지 않는 이유: 원본 35 MB를 그때그때 받으면 모바일 회선에서 수 초~수십 초가 걸리고 오프라인에서 지도가 열리지 않으며 제3자 호스팅(GitHub)의 가용성·요청 제한에 기대게 된다. 병합·단순화하면 수백 KB 수준이라 내장이 즉시·오프라인으로 열린다. 핀은 정확한 좌표에 찍히므로 경계의 세밀도와 무관하다.
- 투영: 한반도 범위의 등장방형(경도에 cos 36° 보정). `lat/lng ↔ 지도 좌표` 변환 함수를 함께 둬서 핀 표시와 탭 위치 지정에 쓴다.
- 구현 결과(2026-09): ver20260701 원본의 `sgg` 코드는 256개(일반구를 따로 셈, 전남광주통합특별시·인천 개편 반영)라 시·군·구 지도도 256개 구역으로 그린다. 생성 Kotlin 약 235 KiB(좌표 약 5만 점), 0.5 km² 미만 섬 조각만 제외.

### 1.2 화면
- 원두 탭 › 로스터리 › 한국: 기존 "KOREA" 자리 표시 도형을 실제 전국 지도(시·도 경계)로 바꾼다. 시·도를 누르면 그 시·도의 시·군·구 지도로 확대(핀치 줌·이동), 뒤로 가면 전국.
- 핀: 좌표가 있으면 그 좌표, 없으면 위치 텍스트에서 찾은 시·군·구(없으면 시·도)의 중심. 같은 곳의 여러 핀은 겹치지 않게 벌린다. 핀을 누르면 기존 로스터리 패널 + "네이버 지도에서 열기", "카카오맵에서 열기".
- 방문 카페 토글: 같은 지도에 카페 기록의 카페를 표시(1.4).

### 1.3 위치 지정 (지도에 직접 표시)
- 로스터리 폼에 "지도에서 위치 지정": 전국 → 시·도 → 시·군·구 순으로 확대해 탭하면 좌표 저장, 소속 시·도·시·군·구를 경계 판정(point-in-polygon)으로 구해 위치 칸이 비어 있으면 "서울특별시 성동구"처럼 채운다. 좌표 지우기 지원.
- 저장: `misc_items`에 `lat`, `lng`(nullable) 열 추가(Room v2 자동 마이그레이션). 백업 `miscItems` 객체에 `lat`, `lng` 키를 더한다(웹은 모르는 키를 무시하고, 앱끼리는 왕복 보존).

### 1.4 방문 카페
- 카페 기록(카테고리 카페)의 카페 이름별 위치를 새 테이블 `cafe_places(name PK, lat, lng, created_at)`에 저장(v2 마이그레이션에 함께). 백업 확장 키 `cafePlaces`.
- 카페 기록 상세·달력의 카페 목록에서 "지도에서 위치 지정". 지도에는 방문 횟수와 함께 표시, 핀을 누르면 그 카페의 기록 목록.
- 이후(v1.2.0): 이름은 "카페 지도". 방문 기록 없이 "+ 카페 추가"로 등록한 카페도 이 표의 행으로 보이고, 위치 지정에서 주소·이름 검색과 "현재 위치"가 생겨 `cafe_places`에 `address` 열이 더해졌다(Room v3).

### 1.5 지도 앱 링크 (공식 문서 기준, API 키 불필요)
- 네이버 지도 앱: `nmap://place?lat=…&lng=…&name=…&appname=com.coffeejournal.app`(좌표 있을 때), `nmap://search?query=…&appname=…`(없을 때). 앱이 없으면 `https://map.naver.com/p/search/{이름 지역}` 웹으로.
- 카카오맵: `https://map.kakao.com/link/map/{이름},{위도},{경도}` 또는 `https://map.kakao.com/link/search/{검색어}`(PC·모바일에 맞춰 열림).
- 해외 로스터리: 네이버·카카오의 해외 검색이 약하므로 Google 지도 공식 Maps URL `https://www.google.com/maps/search/?api=1&query=…`도 함께 제공.

### 1.6 해외 로스터리 지도
- 기존 "WORLD" 자리 표시 도형을 앱에 이미 있는 Natural Earth 세계지도로 바꾼다. 좌표가 있으면 그 위치, 없으면 위치 텍스트의 나라(기존 국가 판별 규칙) 중심에 핀. 위치 지정은 세계지도에서 탭.

### 1.7 상세 지도 (하이브리드, 2026-09 사용자 결정 "A")
- 결정: SGIS 한국 지도(전국 → 시·도 → 시·군·구, 앱 내장·오프라인)는 그대로 두고, 도로·하천·건물·지명이 보이는 **OpenStreetMap 상세 지도**를 더한다. 시·도/시·군·구 지도나 핀에서 "상세 지도"로 들어가고, 위치 지정에서는 상세 지도로 정확한 자리를 찍는다.
- 데이터: [OpenFreeMap](https://openfreemap.org/) 공개 인스턴스의 벡터 타일(OpenStreetMap 데이터, 스키마는 수정 없는 OpenMapTiles). TileJSON `https://tiles.openfreemap.org/planet`, 라틴 글리프 `https://tiles.openfreemap.org/fonts/{fontstack}/{range}.pbf`("Noto Sans Regular"). 키·계정·쿠키 없음, 상업적 사용 허용, 출처 표시 필수(2026-09 사이트·약관·개인정보 처리방침 확인). `tile.openstreetmap.org`는 쓰지 않는다(타일 정책상 앱의 대량·오프라인 사용 금지).
- 요청 범위: 화면에 보이는 지역의 타일만 받는다. 미리 받기·일괄 다운로드 없음. MapLibre 기본 앰비언트 캐시(기기 안, 백업 규칙에 포함되지 않음)만 쓴다.
- 렌더러: MapLibre Compose 0.12.1(BSD-3-Clause, Kotlin 2.2.21·CMP 1.9.x로 빌드된 마지막 릴리스; 0.13부터 Kotlin 2.3 필요) + MapLibre Native(BSD-2-Clause) — Android는 MapLibre Native Android 12.0.1, iOS는 MapLibre Native iOS 6.17.1(maplibre-compose 0.12.1이 빌드된 버전, 공식 Swift 패키지 `maplibre-gl-native-distribution`을 Xcode 프로젝트가 링크). 화면은 `DetailMapRenderer` 인터페이스만 보고, 지도 그리기(`MapLibreDetailMap`: 카메라·핀 레이어·탭 판정)는 `commonMain`에서 두 플랫폼이 같이 쓴다. 플랫폼 몫(`MapLibreDetailMapRenderer`)은 온라인 확인(Android `ConnectivityManager`, iOS Network 프레임워크 경로 모니터)과, Android에서 네이티브 라이브러리를 먼저 올려 보고 못 올리면 실패로 알리는 것뿐이다.
- 스타일: 앱 코드의 `DetailMapStyle`(style spec v8) — 아이보리 #F5F4EF 땅, 청회색 물, 옅은 녹색 공원·숲, z14부터 옅은 회색 건물, 흰 도로 + 도로 등급별 잉크 테두리, `name:ko`(없으면 `name`) 잉크 #191916 한국어 라벨, 카페 POI는 갈색. 스프라이트(아이콘) 없음. 한글·한자·가나는 기기 글꼴로 그리므로(MapLibre local ideographs) 한글 글리프는 받지 않는다.
- 핀: SGIS 지도와 같은 데이터·키(로스터리: 좌표, 없으면 지역 글의 시·군·구/시·도/나라 중심 — 중심 핀은 속 빈 원; 방문 카페: 위치 지정된 카페). 핀을 누르면 SGIS 지도와 같은 패널(기록, 네이버·카카오, 해외는 Google).
- 출처 표시: 지도 위에 항상 "© OpenMapTiles © OpenStreetMap contributors"(누르면 OSM 저작권 페이지). `출처 · 라이선스`에 OpenStreetMap(ODbL 1.0)·OpenMapTiles·OpenFreeMap·MapLibre와 MapLibre Native가 함께 넣은 C++ 라이브러리 고지 원문(플랫폼마다 그 플랫폼 MapLibre Native의 LICENSE.md: Android `platform/android`, iOS `platform/ios`). iOS 라이브러리 목록에는 POM이 없는 MapLibre Native iOS를 따로 덧붙인다(BSD-2-Clause).
- 개인정보: 상세 지도를 열 때만 보이는 지역의 타일·글꼴 조각을 OpenFreeMap(Cloudflare CDN 경유 가능)에 요청한다. 요청에는 여느 HTTP 요청처럼 IP 주소와 User-Agent(앱 이름·버전, MapLibre·Android 또는 iOS 버전)가 담기고, 기록·로스터리·카페 정보는 보내지 않는다. 위치 권한은 쓰지 않는다(Android: MapLibre가 선언한 위치·Wi-Fi 권한은 매니페스트에서 제거; iOS: 사용자 위치를 켜지 않으므로 Info.plist에 위치 문구를 두지 않는다).
- 오프라인·실패: 열 때 네트워크가 없으면 안내 + "한국 지도로 돌아가기"·"다시 시도". 네이티브 라이브러리를 못 올리거나(Android) 스타일이 실패하면 같은 안내. 20초가 지나도 다 못 받으면 지도 위에 알림. SGIS 지도는 네트워크 없이 그대로 동작한다.
- APK: 네이티브 라이브러리(4개 ABI, 압축 전 약 49 MB)를 압축 저장해 릴리스 APK가 약 15.9 MiB → 31.2 MiB(설치 시 기기 ABI만 풀림). 알림·위젯과 병합한 뒤에는 약 17.7 MiB → 33.0 MiB. 이후 x86·x86_64를 빼서(ARM 두 ABI만, 사용자 결정) 약 23.1 MiB.

## 2. 기록·분석

### 2.1 추출 타이머
- 기록 폼 단계 로그의 "⏱ 타이머로 기록" → 전체 화면 타이머: 시작·일시정지·초기화, "붓기 시작/끝"(끝날 때 물량 입력), 뜸·스월·드로우다운 메모 버튼. 종료하면 단계 로그로 옮긴다(기존 로그가 있으면 교체 확인).
- 레시피가 적용돼 있으면 다음 단계까지 남은 시간과 목표 물량을 보여주고 단계 전환 때 진동. 타이머 중에는 화면을 켜 둔다. 진동·화면 유지는 플랫폼 경계(expect/actual).
- 이후: 붓기 끝에서 물량 입력을 기다리지 않고 어림 물량(레시피 목표, 없으면 초당 6g을 10g 단위로)이 옅게 들어가 누르면 고친다(v1.1.0). 잘못 누른 푸어는 옆의 옅은 ✕로 지우고 "되돌리기"로 되살린다(v1.2.0).

### 2.2 추출 비교표 · 계산기
- 홈 원두 그룹을 펼친 곳에 "추출 비교": 같은 원두 기록을 열로 나란히(날짜, 원두량, 물량, 비율, 온도, 분쇄도, 총시간, 점수, 노트). 베스트 레시피(없으면 최고 점수)와 다른 값을 강조.
- 계산기(기록 폼 레시피 영역): 비율 1:x ↔ 원두량·물량, TDS(%)와 추출액 무게로 추출수율 EY = TDS × 추출액 ÷ 원두량. SCA 기준 범위와 비교해 보여주고, 결과를 메모에 붙일 수 있다. 기준 수치는 SCA 공식 자료와 대조해 출처를 남긴다.

### 2.3 SCA CVA 양식
- 테이스팅·커핑 원두마다 "SCA 2004 | CVA" 양식 선택. 기존 2004 기록은 그대로.
- CVA 서술 평가(SCA-103)와 정서 평가(SCA-104)의 항목·척도·점수식은 SCA 공식 표준/계산기와 대조해 구현하고, 대조한 출처를 코드 주석과 출처 화면에 남긴다.
- 저장: 스키마를 바꾸지 않고 기존 JSON 점수 맵(`attributes`, 커핑 원두 `evaluation_scores`)에 `cva.` 접두 키로, 선택 서술어는 기존 JSON 열에 둔다. 웹은 모르는 키를 무시한다.

### 2.4 통계 화면
- 홈 액션 줄에 "통계". 기간(이번 달 / 3개월 / 올해 / 전체)별로 잔 수(월별 막대), 원두 사용량, 지출(봉투 가격 ÷ 용량 × 원두량), 산지·가공·품종·로스터리 상위 분포, 점수 추이, 비율·온도와 점수의 산점도. 모두 기기 안에서 계산하고 아카이브 스타일(헤어라인·모노 숫자)로 Canvas에 그린다. 차트 라이브러리는 추가하지 않는다.

## 3. 알림 · 위젯 (Android 먼저, iOS는 같은 규칙으로 추후 — 이후: iOS 알림은 미리 예약 방식으로 구현, 위젯은 Android만)
- 알림: 하루 한 번 점검(WorkManager)해 ① 보관함 원두의 예상 피크 시작일 ② 잔여량이 평소 원두량 기준 2잔 이하 ③ Coffee D-day 마일스톤을 알린다. 항목별 켜기/끄기(기타 탭 하단 "알림 설정"), Android 13+ 알림 권한 요청.
- 홈 화면 위젯(Jetpack Glance): D-day, 마시는 중 원두·잔여량, "+ 새 기록"(앱의 새 기록 폼으로 바로).
- 새 의존성(androidx.work, androidx.glance)은 공식 Google Maven 산출물이며 체크섬 파일과 라이선스 목록을 함께 갱신한다.

## 4. 고정 서명 키 · CI
- 릴리스 서명: 환경 변수(`COFFEEJOURNAL_KEYSTORE_BASE64/…_PASSWORD/…_ALIAS/…_KEY_PASSWORD`)가 있으면 그 키로 서명, 없으면 로컬 빌드는 디버그 키.
- GitHub Actions: 푸시·PR마다 단위·흐름 테스트, 서명된 릴리스 APK 빌드, 결과물(아티팩트) 업로드. `v*` 태그는 GitHub Release에 APK 첨부. 저장소 비밀(Secrets)이 없으면 서명 없이 테스트만 통과시키고 알린다.
- 이후: 태그 `v*` 또는 main에서 release 입력으로 돌린 Android·iOS 워크플로가 버전 릴리스 하나에 APK와 서명 없는 .ipa를 함께 붙인다. 버전 릴리스는 쌓이고(v1.1.0, v1.2.0 …) 가장 새 것이 Latest다.
- 키 교체 안내: 지금까지 설치한 APK는 디버그 키라, 고정 키 APK로 처음 바꿀 때 한 번은 백업 → 삭제 → 설치 → 복원이 필요하다. 이후 업데이트는 덮어 설치.
